# isahhah.com

**Build your strength.**

Personalised home calisthenics, inspired by the Maltese meaning of “isahhah”.

## First release

- Three weeks of varied training, with three strength days and up to two optional conditioning days per week.
- Beginner, regular and advanced exercise options selected through onboarding.
- Maximum 15 active minutes per session, including warm-up and cooldown; rest is tracked separately.
- Mat and sturdy chair as the default equipment.
- Adult female exercise instructor in an olive sports top and charcoal athletic shorts.
- Female coaching voice, optional background music and separate countdown controls.

## Project status

Training program and instructor style approved. The demonstration clip is being revised to use shorts. This repository currently contains the training specification; the web application and full exercise-video library are the next implementation stage.

## Deployment direction

Application code belongs in this repository. Host on Vercel and connect **isahhah.com**, managed through GoDaddy, when the app is ready. No deployment or DNS changes have been made as part of repository initialisation.

See [the three-week training program](docs/training-program.md).
